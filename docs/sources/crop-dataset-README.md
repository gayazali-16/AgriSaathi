# Crop Research Dataset

## Overview

This repository contains a comprehensive agricultural dataset curated for research in crop prediction, yield estimation, irrigation analysis, and data-driven agricultural decision-making for the Indian population.

The dataset integrates multiple verified governmental and institutional agricultural data sources into a unified machine-learning-ready tabular dataset designed to support agricultural analytics, machine learning, explainable AI (XAI), and precision farming research.

## Features Included

## Data Processing and Preprocessing

The dataset was constructed using a systematic preprocessing and integration pipeline that included:

- Multi-source data integration
- Text standardisation
- Unit normalisation
- Composite key-based dataset merging
- Missing value handling
- Regression-based imputation
- Validation against official agricultural taxonomies

The objective was to create a reliable, structured, and machine-learning-ready agricultural dataset suitable for large-scale analytical and predictive applications.

---

## Data Sources

The dataset was compiled using verified governmental and institutional repositories, including:

1. NASA POWER API
2. Open Government Data Platform India
3. ICRISAT Data Repository
4. Tamil Nadu Agricultural University
5. Indian Council of Agricultural Research (ICAR)
6. Indian Institute of Spices Research (IISR)
7. NITI Aayog Groundwater Data

---

## Research Context

This dataset was developed as part of the research study:

**"An Agricultural Dataset designed for XAI Decision Making for the Indian Subcontinent"**

The study focuses on addressing the limitations of fragmented agricultural datasets by integrating climate, soil, fertilizer, irrigation, and production-related variables into a single structured resource.
